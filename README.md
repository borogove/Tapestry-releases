Tapestry: A Specialized Audio Editor

I found existing audio editors to be clumsy for my music-making workflows, so I vibe-coded an editor specialized to my needs. 


Some features:
* Windows, MacOS, and Linux versions
* Multiple-clip sessions
* Conventional cut and copy with several different ways to paste - insert or overdub, with or without crossfades to smooth transitions
* Onset detection to help select material at beat boundaries
* Selection cropping and silence trimming
* Tempo detection
* Loop extraction with crossfading to smooth transition, either tempo-based or from selection
* Folding and rotation
* Normalization
* Extreme stretch (a la Paulstretch)
* Impulse response convolution with smooth looping
* Noise burst generation to quickly create IRs
* Resampling, transposition, time-stretching
* Wavetable generation

For more information see the USER GUIDE.
